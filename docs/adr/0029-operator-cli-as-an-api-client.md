# ADR-0029: An operator CLI (`apps/cli`) that talks only to the public API — device-flow login for Admins, the operator token for Operators

- **Status:** Proposed — to be implemented by the CLI epic
- **Date:** 2026-10-18
- **Deciders:** @itsDaiton
- **Related:** [ADR-0027](./0027-admin-role-two-factor-full-read-and-audit-log.md) — Admins and the admin API; [ADR-0020](./0020-runtime-log-level-switching.md) — the operator token

## Context

Operating the deployment is done today with `curl` and the operator token (log levels). Granting the first Admin needs the same. Admin work (listing Users, bans, the Audit log) should be scriptable too. A CLI is also a deliberate learning goal.

## Decision

1. **A new app, `apps/cli`.** It is a runnable program with its own `bin` and release, not a lib.
2. **It is a client of the public HTTP API only**, through a fetch client generated by Orval from `openapi/`. It never connects to Postgres or Redis, so it goes through the same authorisation and the same Audit log as the dashboard.
3. **Two credentials:**
   - **`nebula login`** uses the OAuth 2.0 Device Authorization Grant (RFC 8628, better-auth's device authorization plugin) and acts as a signed-in Admin. 2FA applies in the browser where the code is approved.
   - **The operator token**, read only from `NEBULA_OPERATOR_TOKEN` and never written to disk, covers Operator commands, including granting the first Admin.
4. **Stack:**
   - commander for commands, `@clack/prompts` for interaction;
   - `--json` on every command;
   - config and profiles (server URL per profile) in `~/.config/nebula-chat/`;
   - the session token in the OS keychain (`@napi-rs/keyring`), falling back to a `0600` file.
5. **Distribution starts workspace-only** (`pnpm nebula …`). Publishing to npm comes later.

## Alternatives considered

- **Operator token only.** No login to build, but no Admin work from the terminal.
- **Direct database access from the CLI.** Bypasses authorisation and the Audit log.
- **oclif.** Plugins and generators we don't need; commander is enough.
